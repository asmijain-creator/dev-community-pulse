The cut: AI tags and writes, code counts

Gemini only labels posts and writes the brief. Mention counts and the week-over-week % change are plain SQL, so “false positive rate: 4 → 14” is exact and repeatable.

Why stable pain-point labels

Gemini is given last week’s labels from Supabase and reuses them, so “false positives” and “too many false alarms” land in one bucket and trends stay comparable.

Running cost

Estimated ~300 posts a week ≈ 100k Gemini Flash tokens: inside the free tier, a few rupees a month if paid. HN, Stack Exchange, GitHub, Supabase, Resend and Vercel Hobby are free.
